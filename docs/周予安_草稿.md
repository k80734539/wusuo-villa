# 周予安：《霧鎖山莊》補寫草稿

> 語氣：話少、冷靜，有時直白到傷人，但不毒舌。
> 不動任何謎題與答案，只加 4 處。確認後才會放進遊戲。
> 台詞格式沿用遊戲內的寫法（`say('角色','台詞')`、`N('旁白')`）。

---

## ① 序章：他的筆記本（插在「傳說什麼的我不信」那句之後）

```
N('我翻開筆記本。第一頁，只有一行字：「紀錄不改。」');
say('kai','學弟，你整天寫寫寫，不累嗎？');
say('an','不寫，會忘。……忘了，就沒辦法對。');
say('kai','對什麼？');
say('an','對自己。');
```

重點：先讓玩家認識他「用紀錄保護自己」。

---

## ② 中段：太直白的一句話（插在與學妹佳穎對話、問她照片之後）

情境：佳穎怕黑，昨晚拍照時手一直在抖。她把照片遞給他，小聲說「我是不是很沒用」。

```
say('ying','……我是不是，很沒用？我連照片都拍歪了。','nervous');
say('an','照片是證據，不是安慰。歪了，也有用。','normal');
N('她沒有回話。手機螢幕暗下去，她低頭，把手縮回袖子裡。');
N('我低頭看自己的筆記本。剛剛那句話，我已經寫了一半。');
say('an','……這句，不用記。','normal');
N('我把那一行，劃掉了。這是我第一次，劃掉紀錄。');
say('an','妳拍的角度，剛好拍到了傘架上的 5 把傘。沒有妳，這個案子，我們根本查不下去。','normal');
say('ying','……真的嗎？','normal');
say('an','真的。這句，可以記。','normal');
```

重點：他的缺點（直白）與一次小小的改變（劃掉紀錄、補一句實話）。

---

## ③ 指認阿哲之前：證據夠了，但還缺一個「為什麼」

插在 `accuse()` 開頭，進入拼圖之前。只播一次。

```
N('所有的證據，都到手了。月牙鎖、釣魚線、舊照片。鏈條，完整。');
say('chen','小子，想清楚了？','normal');
say('an','邏輯上，沒有問題。','normal');
say('chen','那你怎麼還站著不動？','normal');
say('an','……紀錄只能寫「發生了什麼」，寫不了「為什麼」。','normal');
say('chen','指認以後，他自然會說。','normal');
say('an','那是他被逼到牆角以後，說的話。','normal');
N('我把筆記本闔上。');
say('an','我會指認他。然後，我會聽完。','normal');
```

重點：他不是同情，而是想知道「為什麼」。這是他跟許晴不同的地方，也是下一步成長的起點。

---

## ④ 結尾：筆記一頁（接在社長遺物那一段之後，取代單純的「剩下的，我會查下去」）

```
N('那朵雲，我看了很久。手指，停在紙上。');
say('an','……','normal');
N('我把那份文件，收進筆記本的最後一頁。');
showDoc('〈周予安的筆記　霧鎖山莊〉\n\n01:00　傘被風吹飛。機關成立。\n03:10　證據鏈完整。可以指認。\n03:12　不確定，指認之後，要對誰說什麼。\n05:40　他哭了。我沒有記這一行。\n\n結論：\n證據對了，答案還缺一個人的理由。\n\n（另：社長的牛皮紙袋。雲朵。\n　這個名字，我不是第一次看到。——繼續查。）');
say('an','……剩下的，我會查下去。','normal');
```

重點：
- 「我沒有記這一行」呼應②劃掉紀錄，也呼應夜市那頁「我的紀錄裡，從來沒有這一行」。
- 「我不是第一次看到」是給後面夜市的伏筆（他媽媽的店），但不在這裡說破。

---

## 銜接《夜市無聲》

夜市結尾的筆記有一句「她說：『線會告訴人，該去看哪裡。』我說：『線不是證據。』」。
這份草稿讓山莊裡的他先學到一件事：紀錄可以劃掉、可以不記。到了夜市，他才更能接受許晴的方法。

## 需要你確認

1. ② 的「我是不是很沒用」要不要由佳穎說，還是改成志明？
2. ④「我不是第一次看到」會不會太明顯？想更隱晦可以刪掉，只留「雲朵」。
3. 語氣：他的台詞是否夠像他？尤其是 ③「那是他被逼到牆角以後，說的話」這一句。
